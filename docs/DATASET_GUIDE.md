# NetSentinel AI — Dataset Guide & Public Intrusion Detection Benchmarks

This guide explains how to obtain, inspect, and evaluate network traffic datasets using NetSentinel AI.

---

## 1. Supported Benchmark Datasets

NetSentinel AI is built to ingest and process common public network security datasets:

### A. CIC-IDS2017 (Recommended)
- **Publisher**: Canadian Institute for Cybersecurity, University of New Brunswick (UNB)
- **Official Source**: [UNB CIC-IDS2017 Official Portal](https://www.unb.ca/cic/datasets/ids-2017.html)
- **Format**: Pre-extracted flow CSVs generated by CICFlowMeter.
- **Traffic Days**:
  - `Monday-WorkingHours.pcap_ISCX.csv` (Benign baseline)
  - `Tuesday-WorkingHours.pcap_ISCX.csv` (FTP-Patator, SSH-Patator brute-force)
  - `Wednesday-WorkingHours.pcap_ISCX.csv` (DoS / Heartbleed)
  - `Thursday-WorkingHours-Morning-WebAttacks.pcap_ISCX.csv` (SQLi, Brute Force, XSS)
  - `Friday-WorkingHours-Afternoon-PortScan.pcap_ISCX.csv` (Port Scanning)
  - `Friday-WorkingHours-Afternoon-DDos.pcap_ISCX.csv` (DDoS)

### B. Synthetic Research Fixture (Built-In)
- If you do not have a 2GB+ CIC-IDS2017 file downloaded, click **"Generate Research Sample"** in the **Traffic Analysis** page.
- NetSentinel AI creates an immediate 400-row synthetic flow capture simulating realistic benign flows, SSH brute force attacks, and SYN port scans with zero manual setup.
- This sample is clearly tagged as synthetic in metadata.

## 2. Ingestion Pipeline & Safety Features

When a CSV is uploaded to NetSentinel AI:
1. **Validation**: Enforces strict CSV header validation, file size limits (default 100MB, configurable), and rejects non-CSV MIME types.
2. **Column Role Identification**:
   - Matches label/target columns (e.g. `Label`, `class`, `attack_type`).
   - Identifies source/destination IPs and ports for Topology & Correlation.
3. **Infinite & NaN Value Imputation**:
   - Replaces `np.inf` / `-np.inf` (frequent in CICFlowMeter's `Flow Bytes/s` calculations) with column medians.
4. **Target Leakage Prevention**:
   - Strips the label column and identifier fields from the input feature matrix $X$ before model fitting.

---

## 3. Uploading Custom Datasets

1. Open NetSentinel AI in your browser (`http://localhost:5173`).
2. Go to **Traffic Analysis** in the left sidebar.
3. Click **Upload CSV Dataset**.
4. The system validates the schema and loads an interactive 50-row preview with missing value counts and data types.
